ДЕНЬГИ — приложение для iPhone (оболочка Xcode вокруг dengi.html)

Нужно на MacBook: Xcode (из App Store), Node.js, CocoaPods (brew install cocoapods).

1. Распакуйте папку, откройте в ней Терминал.
2. npm install
3. npx cap sync ios        (подтянет плагин голоса и сделает pod install)
4. open ios/App/App.xcworkspace      (именно .xcworkspace, не .xcodeproj)
5. В Xcode: слева выберите проект App → вкладка Signing & Capabilities →
   Team: ваш Apple ID (Xcode → Settings → Accounts → добавить Apple ID).
   Если пишет, что Bundle Identifier занят — смените com.valexlabl.dengi на свой, например com.ваше-имя.dengi.
6. Подключите iPhone кабелем, выберите его сверху вместо симулятора, нажмите ▶.
7. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».
   (При первом запуске: Настройки → Конфиденциальность → Режим разработчика → включить.)

Бесплатный Apple ID: приложение работает 7 дней, потом нужно снова нажать ▶ в Xcode (данные сохраняются).
Платный аккаунт ($99/год): без ограничения по 7 дням.

ДАННЫЕ: приложение хранит их отдельно от иконки на экране. Перенос: в старой «Деньги» → Данные → экспорт в файл,
в новом приложении → Данные → импорт.

Обновить приложение после правок dengi.html: заменить www/index.html (кроме блока «Нативная оболочка» вверху) и снова npx cap sync ios.
