# Датчики дома

Одна панель на iPhone для всех датчиков: Wi-Fi и Bluetooth, через хаб Xiaomi.
Показывает температуру, влажность, батарею, двери, движение, протечки,
рисует графики за сутки, неделю и месяц, включает и выключает розетки.

## Как это устроено

```
Bluetooth-датчики ─► хаб Xiaomi ─┐
Wi-Fi датчики Xiaomi ────────────┼─► облако Mi Home ─► ХАБ-ПРОГРАММА ─► панель на iPhone
Wi-Fi устройства Shelly ─────────────────────────────►  (ваш компьютер)   (Safari, Wi-Fi дома)
Bluetooth напрямую (адаптер ПК) ─────────────────────►
```

- **Хаб-программа** (`hub/`) работает на компьютере дома и собирает датчики из всех источников.
- **Панель** (`docs/index.html`) открывается на iPhone по адресу хаба и добавляется на экран «Домой».
- **GitHub** хранит весь код. Та же панель публикуется на GitHub Pages в демо-режиме.

## Запуск без компьютера: хаб на сервере

Достаточно iPhone и любого сервера Linux (VPS). Через сервер работают устройства
из Mi Home: Wi-Fi, а также Bluetooth и Zigbee через хаб Xiaomi. Источники
«Bluetooth напрямую» и Shelly на сервере недоступны: им нужна домашняя сеть.

1. Подключитесь к серверу (например, через Termius) и выполните:

   ```
   git clone https://github.com/labuzin-maker/dengi-ios.git
   cd dengi-ios/sensor-hub && bash install.sh
   ```

2. Скрипт напечатает адрес панели и ключ доступа. Откройте адрес в Safari, введите ключ.
3. В панели: кнопка справа вверху → «Войти в Mi Home» → ссылка «откройте страницу
   входа Xiaomi» (QR-код с того же телефона не отсканировать). Войдите в аккаунт Mi.
4. «Поделиться» → «На экран Домой».

Хаб запускается сам после перезагрузки сервера. Обновление: `git pull && bash install.sh`.

**Https и панель с GitHub Pages.** Пока хаб открыт по `http://`, ключ доступа
передаётся без шифрования. Поставьте хаб за nginx с сертификатом
(пример: `deploy/nginx.conf.example`). После этого панель на GitHub Pages тоже
работает с живыми данными: откройте её, кнопка справа вверху → впишите адрес хаба.

## Запуск на Windows

1. Установите Python 3.11 или новее с python.org (галочка «Add python.exe to PATH»).
2. Скачайте репозиторий (Code → Download ZIP), распакуйте и откройте папку `sensor-hub`.
3. Дважды щёлкните `start.bat`. Первый запуск ставит компоненты, потом хаб печатает два адреса.
4. Если Windows спросит про брандмауэр, разрешите доступ в частных сетях.
5. На компьютере откройте `http://localhost:8080`: появятся примеры датчиков.

## Подключение Xiaomi

1. В панели нажмите кнопку справа вверху → «Войти в Mi Home».
2. Отсканируйте QR-код приложением Mi Home на телефоне и подтвердите вход.
   Пароль хабу не нужен и нигде не хранится.
3. Через минуту примеры сменятся вашими устройствами, с комнатами из Mi Home.

Новый датчик добавляйте как обычно, в Mi Home. В панели он появится сам в течение 10 минут.

## iPhone

Телефон должен быть в том же Wi-Fi. Откройте в Safari адрес из окна хаба
(вида `http://192.168.1.50:8080`), затем «Поделиться» → «На экран Домой».
Чтобы адрес не менялся, закрепите за компьютером IP в настройках роутера.

## GitHub

Код лежит в репозитории `labuzin-maker/dengi-ios`, в папке `sensor-hub`.
Если для репозитория включён GitHub Pages (Settings → Pages, ветка `main`, папка `/`),
панель открывается по адресу `https://labuzin-maker.github.io/dengi-ios/sensor-hub/docs/`.

Страница на GitHub Pages сама показывает примеры. Живые данные она покажет,
если у хаба есть адрес с `https://` (хаб на сервере, см. выше): впишите его в панели.
К хабу на домашнем компьютере по `http://` страница с GitHub обратиться не может,
это запрет браузеров.

Файлы `data/` и `config.yaml` в GitHub не попадают (см. `.gitignore`).
В `data/xiaomi_session.json` лежит доступ к вашему аккаунту Mi Home: никому его не передавайте.

## Настройки

Скопируйте `config.example.yaml` в `config.yaml`. Там порт, ключ доступа к панели
и источники: Xiaomi, Bluetooth напрямую, Shelly.

## Что проверено и что нет

Проверено автоматическими тестами (`python -m unittest tests.test_all`):
шифрование и подпись запросов Xiaomi (сверены с эталонной реализацией),
работа драйвера с имитацией облака Xiaomi и устройства Shelly,
разбор Bluetooth-пакетов BTHome, ATC/pvvx и MiBeacon, API хаба и панель.

Не проверено на настоящем аккаунте Xiaomi и настоящих датчиках.
Известные ограничения:

- Датчики движения и открытия, которые сообщают только события, могут показать
  не всё. Откройте `http://localhost:8080/api/diagnostics` и пришлите вывод:
  по нему добавляется поддержка конкретной модели. Секретов в выводе нет.
- Данные Xiaomi идут через облако, поэтому нужен интернет, а показания
  обновляются раз в минуту.
- Bluetooth-датчики Xiaomi с шифрованием читаются только через хаб Xiaomi.
- Хаб работает, пока включён компьютер. Для круглосуточной работы подойдёт
  мини-ПК или Raspberry Pi: код тот же, запуск `python -m hub`.

## Как добавить свой источник

Создайте файл в `hub/drivers/` с классом-наследником `Driver` (пример: `shelly.py`,
90 строк) и впишите его в `hub/drivers/__init__.py`.

Вход в Xiaomi и формат запросов сверены с открытым проектом
PiotrMachowski/Xiaomi-cloud-tokens-extractor (лицензия MIT).
